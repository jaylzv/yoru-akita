# Yoru Akita

A Claude Code theme: a calm pixel-art night in Japan. An Akita Inu and Clawd sit by a stone lantern under a cherry blossom tree, watching the moon over a still lake with a torii, a pagoda and a snow-capped volcano. Stars twinkle, petals drift, fireflies wander, and the lantern flickers. Motion stops when your system asks for reduced motion.

The look is dark mode only and draws in the Claude desktop and mobile apps (terminals and editors draw no themes).

## Install

At the prompt of a terminal session:

```
/plugin install yoru-akita --marketplace jaylzv/yoru-akita
```

Or from a shell:

```
claude plugin install yoru-akita --marketplace jaylzv/yoru-akita
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `jaylzv/yoru-akita`, then Add plugin.

This repository is private: installing needs read access on GitHub and a git credential for github.com on the machine (an SSH key, or `gh auth login` then `gh auth setup-git`).
